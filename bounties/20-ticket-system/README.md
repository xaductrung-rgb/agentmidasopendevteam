# Bounty #20: Ticket System ($250)

Support Ticket Creation, Agent Assignment, Status Workflow, and Real-Time SLA Breach Tracking.

## Features
- **Ticket Creation & Priority SLA Assignment**: Create tickets with priority (`Critical`, `High`, `Medium`, `Low`) and automatic SLA target deadlines.
- **Controlled Status Workflow & Agent Assignment**: Transition tickets across `Open -> In Progress -> Waiting on Customer -> Resolved -> Closed`, assign support agents, and log internal/public replies.
- **SLA Due / Overdue Countdown**: Highlights overdue and at-risk tickets in real time.
